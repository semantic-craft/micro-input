# BUILD PROMPT — 分阶段构建与验收 v1.0

本文件替代旧“一发构建”提示。执行前读 [SPEC](SPEC.md) 的产品定位、规则和宿主/设备边界，再读本文件；证据只沿 [EVIDENCE](EVIDENCE.md) 到项目自撰摘要，待确认项见 [UNKNOWNS](UNKNOWNS.md)。不读取厂商代码/资源或用户数据来补协议。本轮授权仅阶段0文档与工单，不运行实机探针、不写设备、不接自动化。

## 每次实现任务的输入与交付

- 明确 `Stage`、目标提交/分支、该阶段允许的副作用、适用规则及未解锁UNKNOWN。没指定阶段时不能默认执行阶段0–6全量产品。
- 主分支基线9e78e8a为文档仓。PR #7/#8已关闭未合并；如接续旧候选，只选择相关原创实现，重新核对v1.0规则并验证，不自动重开或合并旧PR。
- Rust stable五核心模块 + SwiftUI macOS14+；UniFFI进程内静态库、高层异步接口；IOKit/hidapi非独占。若改变已有候选选型，说明当前需求与可验替代，不凭喜好增基础设施。
- 工程建立后提供 `scripts/check` 与真实启动命令；check在干净clone构建Rust/Swift并跑适用测试，不加载凭据。当前只有文档时只检查链接/规则/证据一致性，不伪造应用构建通过。
- 合成向量必须明确标识自编格式；未知设备字段保留raw，真实schema另设可替换边界。每个实现/测试注明规则ID；新的证据先更新EVIDENCE/UNKNOWN，再解锁对应代码。
- 完成回执包含提交、环境、检查命令、成功/失败/未运行、真实副作用和剩余UNKNOWN；构建、模拟、UI、硬件、合并、发布分别报告。
- 当前不新增CI、定时器、自动issue→Run、自动审查或自动应用接线。项目已有平台行为不在本轮改动范围；本地确定性检查正常使用。

## 测试接缝

优先一个共同产品接缝：**高层异步核心API → UniFFI → SwiftUI/未来agent客户端**。MockTransport和内存配置支持真实解析/桥接，无Swift硬编码数据替代。协议分片/校验必须在Framer/Codec边界补测；真实设备/权限/布局只能用实机验收补证。

既有候选先例：非连续Profile ID、raw/未知token、缺失引用、畸形JSON、导航零请求、通知穿插、错ID、超时、pending open期间断开/移除、跨重连旧响应、大整数与同批通知。旧测试可复用，旧通过结论不可直接复用到新提交。

- **AC-0.4** 本地相对链接、规则/证据/UNKNOWN ID引用可解析；按to-spec模板发布新规格issue并标ready-for-agent，明确其不授权全阶段执行。

### S1 — 真实只读查看器

**交付**：可启动原生应用、真实设备只读快照。US-02–US-08、US-38、US-45、US-48；衔接现有 #1及#2–#6。

- **AC-1.1** 干净clone的check编译Rust/Swift，生成并链接真实UniFFI；实际启动演示浏览，显示来源、时间、13开关矩阵、旋钮3槽候选、摇杆摘要；实体图与矩阵区分（R-A01/R-A02/R-C05/R-N04）。
- **AC-1.2** 合成覆盖未知字段/token、大整数、缺失引用、非连续ID/index、畸形布局/JSON；未知不显示为空，活动Profile未经确认显示未知（R-N03）。
- **AC-1.3** 仅通过OS枚举发现候选；VID/PID/usage pairs/USB可解释，多候选明确选择。枚举零RPC且不请求Input Monitoring；实际插拔更新（R-D01/R-D02/R-H02）。
- **AC-1.4** 后端映射有来源；报告report ID处理、长度及收发边界。离线验证61/62/122/123字节、多帧UTF-8、长短字段、连续对象/LF/CRLF、通知/错ID、畸形和内存上限；适配未明则Unverified/no-send（R-D04/R-D05）。
- **AC-1.5** 当前设备通过应用路径查到身份/版本，可选字段缺失显示未知；不是OS版本、缓存或独立探针替代。仅允许有来源的status/version请求，记录实际目标/固件/backend（R-D09）。
- **AC-1.6** list→两份限定文件readbin→字节/摘要核对→再list；keymap缺失失败，smart缺失和空文件分开；空块、非法Base64、总大小漂移、超请求长度、checksum缺失/变化/不匹配都不产生“最新完整快照”（R-C01/R-D08）。
- **AC-1.7** 设备schema独立于演示schema：数字颜色、token保留、SmartActions对象、可选字段、分组兼容和索引分别验；实际读回至少一Profile/Layer可浏览。不能导入Input缓存代替（R-C03/R-C05）。
- **AC-1.8** 每设备单请求在途、间隔/超时策略明确；重复点击不并发；通知穿插及同批响应后的通知不丢；旧/外来/同ID风险有测试与并存限制（R-D05/R-D07/R-N02）。
- **AC-1.9** pending open、读取中断连、重连、锁屏/解锁和退出释放可验；迟到结果不得复活连接或污染新快照。实机断连→重连→再读→退出→重新打开；无硬件即未通过（R-D07）。
- **AC-1.10** 捕获受控出口，证明只有四项候选只读方法及限定文件；导航零请求、无配置同步/预览/激活/宿主执行。核对原有映射行为仍可用，不只比较本地哈希（R-N01）。
- **AC-1.11** 真实交付构建验证权限预检/失败/重检，区分可识别的占用/权限/Secure Input，无法确定则报告未知原因；不修改系统权限或终止其他应用（R-H02）。
- **停止条件**：UNKNOWN-01/03/04/06与后端证据门槛不满足则只交可验证部分；不得因此签收父工单 #1。fs.read不自动加入生产白名单。

### S2 — 离线编辑器

**交付**：设备图编辑、动作库、Profile/Layer草稿与导入导出；US-09–US-22、US-27。允许与S1补证独立推进，但使用自有明确标识的离线格式，不开放设备写入。

- **AC-2.1** 点选实体控件→搜索动作→必要参数→草稿的路径可完成；控件图仅使用已验证映射，未定物理宽键位置明确标注，不猜（R-P02/R-C05）。
- **AC-2.2** 动作搜索/分类/收藏、不可用原因和常驻要求清晰；基础键、宏press/release/delay、Multi四分支、旋钮/摇杆编辑保留未知数据；不臆造范围（R-K01/R-C03）。
- **AC-2.3** Profile/Layer新建、复制、改名、整理，引用唯一性/缺失/冲突校验；撤销/重做、保存重开后相同；导航与草稿操作出口零设备请求（R-E01/R-E02）。
- **AC-2.4** 同时显示基线/草稿/设备活动状态；冲突发生时可选保留草稿、查看设备版或取消，不静默覆盖；不把设备断开当草稿丢失（R-E04）。
- **AC-2.5** 自有导入导出 round-trip 保留raw与引用；厂商格式兼容单独测试，未核实时只声明自有格式；导入不激活、不执行（R-C04/R-C08）。
- **AC-2.6** 键盘操作、标签、焦点和深浅色验收；高级token按需可查，普通流程不要求懂协议（R-P02）。
- **停止条件**：S2无设备写入、预览和宿主动作执行；未确认schema不得生成宣称可直接应用的设备载荷。

### S3 — 可验证的应用与恢复（未来，当前禁执行）

**前提**：S1真实快照/生命周期与S2草稿通过；UNKNOWN-08/09有可靠证据；后续任务明确设备写入和恢复的授权范围。US-23–US-26。

- **AC-3.1** 应用前显示设备身份、草稿修订、基线与差异；读取/比较设备变化，不同基线拒绝盲覆盖；用户一次明确应用只产生一次操作（R-E03）。
- **AC-3.2** 原配置副本可验证且可定位；按已验证协议写入，写后读回核对；send成功、RPC成功、读回相符分别区分（R-E05/R-C02）。
- **AC-3.3** 部分成功、校验失败、超时、拔线、进程退出与重启保留草稿和操作状态；无法确认设备状态时直说未知，不显示成功或自动重试写入（R-E05）。
- **AC-3.4** 恢复先验证目标/副本/协议适用性，真实完成恢复并核对映射；没有可靠恢复保证就不提供“可恢复”承诺，不假设多文件原子事务（R-E05）。
- **AC-3.5** 灯光预览为显式可见的独立设备操作，退出/失败恢复行为经过验证后才启用；浏览灯光参数无副作用（R-E06）。
- **停止条件**：证据或恢复不足不开放生产写入口；本轮任何后续文档读取都不能解除禁写。

### S4 — Coding日常使用

**交付**：通用Coding与工具专用配置、必要宿主执行和最小菜单栏；US-28–US-32、US-35–US-37、US-39–US-40。

- **AC-4.1** 通用编辑器/终端动作有可解释目标与焦点前提；Herdr、DSH、ZCode、QwenWork逐项能力登记，未接工具不显示已支持（R-K01/R-K02）。
- **AC-4.2** 每个专用适配器验证工具不存在/版本不支持/多会话/目标消失/焦点切换/执行失败；若宣称精确会话控制，则在两个同工具会话间证明不会作用于错误目标。快捷键模式单独标识（R-K02）。
- **AC-4.3** kb.sa.*解析与参数校验、输入事件去重、命令默认关、文本粘贴失败与剪贴板并发变化可重放；导入/校验/打开编辑器不会触发执行（R-H05/R-H06/R-H09）。
- **AC-4.4** 每个动作标明设备独立或宿主依赖、可用条件；工具/权限不满足不暗中降级执行；同一通知不被多个宿主重复执行（R-H12/R-K03）。
- **AC-4.5** 菜单栏显示设备与当前生效配置，明确手动切换；关闭主窗保留已启用宿主，退出释放；登录启动默认由用户选择（R-H11/R-K04）。
- **停止条件**：UNKNOWN-07/10/12/13阻止对应动作发布。需要设备新绑定/激活的实机验收须先满足S3条件；可独立完成宿主模拟与自有草稿预设。

### S5 — 切换与体验完善

**交付**：可选前台感知、径向菜单、映射提示、验证过的灯光与性能稳定性；US-18–US-19、US-33–US-34、US-38–US-42、US-47。

- **AC-5.1** 自动切换可启停、状态可见；编辑草稿不自动应用；设备激活与宿主配置切换分别测；快速前台变化、断连、缺配置不错误切换（R-K04/R-H04）。
- **AC-5.2** 径向菜单/提示在多显示器、全屏Spaces、焦点变化、取消/隐藏/拖动下行为正确；摇杆扇区和确认语义已验证（R-H08/R-H10）。
- **AC-5.3** 区域灯/逐键灯、宽键事件、不同层绑定及多宿主所有权分别验收，收到ok但灯无变化不能通过（R-K03/R-C05）。
- **AC-5.4** 先采样建立启动、菜单/切换延迟、idle CPU/RSS、持续运行、设备恢复的基线，再确定可复测预算与观察时长；未定预算不能宣称轻量目标已签收（R-X02，UNKNOWN-15）。
- **AC-5.5** 实际交付签名下的重启/升级权限表现可验；无未解释的反复授权；权限故障和失败信息对用户可理解，诊断不含私密配置（R-H01/R-U02）。
- **停止条件**：性能数值和权限稳定性不可由合成测试替代；BLE不是本阶段隐含交付。

### S6 — Agent协助与扩展

**交付**：结构化读取、草稿操作、解释/校验/差异与适配扩展契约；US-43–US-46。

- **AC-6.1** agent与UI访问同一核心模型/校验；接口带格式/修订版本、来源、能力状态和结构化错误，缺失能力显式返回（R-X01）。
- **AC-6.2** agent修改仅生成草稿；过期修订、非法字段、未知引用不能静默覆盖；用户可在UI审阅差异并拒绝；agent接口没有绕过审阅的原始RPC/设备应用（R-A05/R-X01）。
- **AC-6.3** 新增工具适配以能力声明和契约测试加入，不改变无关设备协议；结果能区分已提交、已执行、无法确认，不能把窗口出现当任务完成（R-K02/R-X01）。
- **停止条件**：无自动分派、定时器或审批代答。接口传输/命令形式为UNKNOWN-18，随实际集成需求确定，不预建服务。
