# Micro Input v0.7.0

本版彻底移除六层方案中的旧版布局兼容双轨，收敛为单一规范六层布局不变量与破坏性原位自动升级模型，彻底消除单键会话状态灯被静默挂起的问题。

- **移除旧版布局兼容双轨（Drop Legacy Six-Layer Compatibility）**：删除 `SixLayerKeymapRevision`、`V1StandardKeys`、`managed_layer_v1` 与 `supports_per_key_led` 等双轨兼容分支；`RunningSixLayer` 仅维护唯一规范六层布局不变量，连接后无条件启动 `SharedVendorBridge` 并通过 `v.oai.thstatus` 实时同步逐键状态灯（运行中呼吸绿光、完成待查看海洋蓝光）。
- **破坏性原位自动升级（Direct Breaking In-Place Upgrade）**：`compile_six_layer_profile` 在保留第 1 层原始 Codex 字节前提下直接覆盖第 2..6 层为规范槽位（`KV_OAI_AG06..AG17`）；`six_layer_runtime::resume` 对未改动的旧版六层快照执行一次性原位 Flash 升级并更新计划快照，保留初始出厂备份 `keymap.json`；若检测到设备曾在外部工具中手工改动，则拒绝静默覆盖并提示显式处理。
- **写前备份与恢复死锁消除**：`merge_previous_original_into_backup` 新增写前设备快照记录（`pre-write-keymap.json`），`restore_six_layer_backup` 接纳该快照校验，彻底消除外部改键后重应用中途断联造成的恢复死锁。
- **结构化冲突拦截与方案保护**：结构化校验第 2..6 层键码，严格拦截退役 `"Cindy"`、`joystick.type == "VENDOR"` 及越位 `KV_OAI_*` 原生键码，防止误伤普通层名；增加 Profile ID 唯一性门禁与重应用时 Karabiner 活动方案一致性检查。
- **发布与测试基建加固**：`test_release_macos_launcher` 改为从 `Info.plist` 动态读取版本元数据，杜绝发版升号后的测试字面量漂移。
- 应用版本更新为 `0.7.0`（build 7），Bundle 标识保持 `craft.semantic.micro-input.dev` 以延续系统辅助功能权限，内部 Rust crate 版本保持 `0.2.0`。
