# Micro Input v0.5.0

本版合入 v0.4.0 之后的轮盘菜单命名统一、通用设置版本与开源信息面板、Sparkle 自动更新客户端，以及面向公开仓库的签名公证发布流水线。

- 工作台「通用」页面新增「版本与软件更新」和「关于与开源」设置组，展示当前应用版本、Bundle 标识、Rust 内核版本（`engine_version`）、MIT 许可证及 GitHub 仓库与发行说明入口；左侧导航栏底部同步显示可点击的版本号徽章。
- 接入 Sparkle `2.9.4` 自动与手动更新客户端，绑定 Ed25519 公钥（`SUPublicEDKey`）与 GitHub Releases 签名更新源（`SUFeedURL`）；通过 `UpdateLaunchPolicy` 在 QA 隔离包、合成验收场景、单元测试、App Translocation 与挂载卷环境下自动停用外部更新检查。
- 补齐原生 macOS 应用主菜单（`关于 Micro Input`、`设置…` `⌘,`、`检查更新…`、标准编辑与窗口菜单），并在菜单栏状态弹层与 Dock 右键菜单提供设置和检查更新入口。
- 新增 `scripts/sign_bundle.py` 由内向外嵌套签名工具与 `scripts/release-macos` 发行脚本，支持 `MI_RUST_PROFILE=release` 编译路径脱敏、Developer ID Application 硬化运行时签名、Apple Notary Service 公证与票据装订、`SHA256SUMS` 校验及 `appcast.xml` 自动生成；补齐根目录 MIT `LICENSE` 与公开仓库文档卫生门禁。
- 应用版本更新为 `0.5.0`（build 5），Bundle 标识保持 `craft.semantic.micro-input.dev` 以延续既有辅助功能授权，内部 Rust crate 版本保持 `0.2.0` 不变。

发布验收覆盖静态边界门禁（`R-C01` 至 `R-C10`）、Rust 与 Swift 全量单元测试、嵌套签名校验及六个隔离合成 QA 场景。实体按键、真实硬件灯效长时稳定性、真实语音、物理睡眠重连和长期运行仍需单独验收，见 #44；软件发布不将这些项目标为通过。
