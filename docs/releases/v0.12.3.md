# Micro Input v0.12.3

本版新增 `Grok Bot`（`com.anysphere.sand`）三键原生无障碍方案替换 `Herdr`，并补齐 Antigravity 中英双语 AX 标签集中管理与 `R-C16` 静态门禁。

- **`Grok Bot` 三键桌面方案与 `Herdr` 自动退役（PR #179）。** 在默认方案与菜单栏槽位中以 `Grok Bot` 替代 `Herdr`，按键位置与 Codex、Antigravity 对齐：`AG06` 为语音聊天（全窗 `AXPress` 切换发起语音聊天与挂断，挂断回读容忍输入框草稿）、`AG11` 为点击听写（含 `AXGroup` / `AXApplicationStatus` 转写状态感知，2U 合并模式自动回落）、`AG12` 为听写激活后发送（录音态直触原生 `sand-prompt-voice-send` 实现自动停录并在转写后发送），其余槽位保持留空。存量 `workbench.json` 中未修改的旧 `Herdr` 方案在启动时自动清理并迁移，用户自定义配置保持不变。
- **Antigravity 双语 AX 标签单源收口与 `R-C16` 门禁（PR #178）。** 将 Antigravity 全部辅助功能控件标签统一收拢到 `crates/mi-macos/src/antigravity_ax_labels.rs`，同时匹配中英文界面下的听写、实时语音、模型选择器、侧栏、内置浏览器与子智能体控件，并通过 `R-C16` 静态门禁禁止在生产代码中散落原始单语字面量。
- **版本信息。** 应用版本 `0.12.3`，build `20`。Bundle 标识、9 函数 C-ABI 边界、持久文档格式与 Sparkle 更新通道保持兼容。

全量离线门禁、静态检查（`R-C01` 至 `R-C16` 及零普通注释校验）、六个隔离 QA 场景与针对运行中 `Grok Bot` 的活体只读 AX 核验均已通过。
