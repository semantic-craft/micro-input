# Micro Input v0.12.0

本版将 Creator Micro 2 会话指示灯重构为「运行静默、待办亮灯」的响应驱动模型，打通六层板载模式下第 1 层 `Codex` 与第 2 层 `Antigravity` 双宿主会话槽位实时共存及存量配置幂等迁移，并完成整仓架构决策沉淀与零普通注释门禁闭环。

- **响应驱动逐键状态灯与底光联动。** 默认关闭运行中会话的绿灯呼吸干扰，将光效留给需要人工介入的事件；已完成未读会话仅点亮对应顶部单键常亮海洋蓝（`e = 1`，不触发底光）；仅当主会话或子代理卡住待审批输入或出现未读报错时，点亮琥珀金（`#FFAA00`）或珊瑚红（`#FF2200`）呼吸灯（`e = 4`），并通过纯 RAM `v.oai.thstatus` 单赢家 `sa: true` 同步底部环境呼吸光，按下物理槽位键、前台查看对应会话或点击「已读熄灯」后自动核销熄灭，全程零设备 Flash 擦写。
- **Antigravity 与 Codex 双源槽位共存及子代理冒泡。** 按 `NeedsAttention < Error < BlueDotCompleted < Working < Idle` 严格排列前 6 槽位，避免活跃后台任务挤掉待响应会话；六层第 1 层 `AG00` 至 `AG05`（`Codex · Micro Input`，恢复并自动迁移存量未修改方案前 6 键为 `slot-open:0..5`）与第 2 层 `AG06` 至 `AG11`（`Antigravity`）各自维护独立目录与修订号，第 3 层非会话键位保持熄灭；补齐 Antigravity 8 跳防环子代理 `waitingSteps` 上卷与 Codex 多窗口项目域侧栏审批徽标扫描及子代理状态上卷。
- **架构决策沉淀与静态质量门禁。** 提炼 18 项系统、USB HID、固件与辅助功能不变量至 [DECISIONS.md](../DECISIONS.md)，拆分 `mi-macos` 的 `codex_sessions` 子模块边界，并在 `scripts/check` 接入零普通注释门禁（`.comment-ratchet.json` `max_total = 0`）。
- **版本信息。** 应用版本 `0.12.0`，build `17`。Bundle 标识、9 函数 C-ABI 边界、持久文档格式与 Sparkle 更新通道保持兼容。

默认并行度下的全量离线门禁、静态检查（`R-C01` 至 `R-C15` 及零普通注释校验）与六个隔离 QA 场景（`host-execution`、`dsh-navigation`、`antigravity-status`、`config-write`、`lighting-control`、`diagnostic-export`）已通过自动回执校验；公证安装后的双源状态灯、存量 `workbench.json` 迁移与 USB 连通已在实机同步确认。
