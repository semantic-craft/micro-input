# Micro Input v0.3.0

本版将原生 Creator Micro 工作台、六层桌面应用控制及运行时一致性修复合入主线。

- 原生 SwiftUI/AppKit 工作台提供独立域刷新、可读会话标题、按键配置与搜索焦点隔离。
- 六层配置保留已有快捷键与应用链接，支持 Codex、Antigravity、DeepSeek Harness、Cindy 的定向控制及设备恢复入口。
- 按住动作保留原始应用与会话身份，松开、睡眠和断连沿同一执行器清理；失败时阻止后续动作冒进。
- 界面投影不触发宿主操作；输入队列有容量和批次限制，旧连接与过期策略事件不能越过停用边界。
- 日常应用版本为 0.3.0（build 3）。内部 Rust crate 版本不在本次应用发布中变更。

发布验收覆盖静态门禁、Rust/Swift 测试和八个隔离合成场景。实体按键、灯效、真实语音、物理睡眠重连和长期运行仍需单独验收，见 #44；软件发布不将这些项目标为通过。

本版为现有 macOS 本机开发签名渠道；不声明公证或新的安装权限。
