# Micro Input v0.11.0

本版合并固件 `0.7.0-rc.16` 按层混合摇杆与鼠标调校、Antigravity 顶部 6 键会话状态与侧栏切换、Codex / DSH 上两排键位重构，并完成纯 Rust 内核、9 函数 C-ABI 边界与 SwiftUI `@Observable` 薄壳的整仓去胶水与严格并发收敛。

- **硬件与预设演进**：默认支持按层混合摇杆模式（Codex / DeepSeek Harness 硬件 `MOUSE` 模式配滑块调校与出厂 `0.15` 防漂移死区默认值，Antigravity 保留四向 `RADIAL` 与左/右划开关右边栏），恢复 Antigravity 顶部 6 槽会话状态灯与 Codex / DeepSeek Harness 顶部 `Subagent` + `左键点击` 预设，并兼容真实 `workbench.json` / `six-layer-runtime.json` 残留槽位就地迁移。
- **架构隔离与模块收口**：默认生产 `mi-ffi` 彻底剥离 `qa-runner`、`synthetic-backend`、`test-util` 与 `mi-bridge`，封堵非隔离模式合成设备快照与模拟按键回退；串口刷机下沉至 `mi-session`，`store.rs` 与 `six_layer_runtime.rs` 拆解为标准目录模块并清零全 workspace（含所有测试目标）Clippy 告警。
- **跨语言边界与 Swift 严格并发**：为 `mi-ffi` 全部 `unsafe extern "C"` 接口补齐 `# Safety` 契约，[CoreBridge.swift](../../app/MicroInput/Sources/MicroInputUI/CoreBridge.swift) 与 [FirmwareUpdate.swift](../../app/MicroInput/Sources/MicroInputUI/FirmwareUpdate.swift) 全面切换强类型 `Codable` DTO 与 `Encodable` 命令编码（消除 4 MB 预设导入装箱瓶颈），并在 `Package.swift` 全量启用 `-strict-concurrency=complete`。
- **版本信息**：应用版本 `0.11.0`，build `12`。Bundle 标识、9 函数 C-ABI 边界、持久文档格式与 Sparkle 更新通道保持兼容。

全量离线门禁、静态检查与六个隔离 QA 场景（`host-execution`、`dsh-navigation`、`antigravity-status`、`config-write`、`lighting-control`、`diagnostic-export`）已通过自动回执校验；实机硬件与公证安装后功能按实机清单分别核验。
