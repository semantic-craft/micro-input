# Micro Input v0.6.0

本版合入 v0.5.0 之后的工作台方案锁定（Profile Lock）、六层输入通道韧性加固，以及 Creator Micro 2 物理小键盘 V2 混合 Vendor 槽位与逐键硬件状态灯联动。

- **工作台方案锁定（Profile Lock）**：在顶部控制栏新增方案锁定开关与状态提示，支持手动锁定当前活跃 Profile（`locked_profile_id`），防止自动跟随切换干扰正在进行的特定编码或文档工作流；解锁后恢复前台应用自动跟随。
- **六层输入通道韧性加固（Six-Layer Input Resilience）**：全面强化 Karabiner 规则生成、动态更新与套接字重连链路；在键盘 USB 热插拔、系统睡眠唤醒或配置重载后建立非阻塞自愈与心跳监测，彻底消除丢键与规则残留风险。
- **硬件六层 V2 混合槽位与逐键状态灯**：小键盘硬件同步升级为 V2 混合 Vendor 槽位（`KV_OAI_AG06..AG17`），打通固件端 OAI Vendor 通道（`v.oai.thstatus`）；当会话运行时物理按键呈现柔和呼吸绿光，完成待查看时呈现清晰海洋蓝光，并在侧栏提供一键恢复出厂配置通道。
- **运行时与会话导航收口**：同步优化多会话槽位切换响应、锁定时状态栏图标显示与单色中性设计系统边界，通过全量单元测试与合成硬件隔离验收。
- 应用版本更新为 `0.6.0`（build 6），Bundle 标识保持 `craft.semantic.micro-input.dev` 以延续系统辅助功能权限，内部 Rust crate 版本保持 `0.2.0`。
