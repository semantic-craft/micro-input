# Micro Input v0.11.2

本版修复 Antigravity 对话切换导致窗口标题变化后的听写租约锁死问题，改进宿主执行异常的菜单栏可见性与恢复路径，并将 Antigravity 内置浏览器切换为直达受控无障碍操作。

- **听写租约容器化与非听写控件解耦**：`mi-macos` 引入按容器身份（`bundle_id + pid + window_id + scope_id`）管理的 `DictationLeaseRegistry`，在 Antigravity 切换对话导致 `AXTitle` 变化后，若同一窗口容器经只读探测确认为 `Idle`，立即自动对账释放过期记录而零按压；旋钮、模型选择、内置浏览器、右边栏与 Subagent 选择器等非听写控件不再受听写未清理护栏阻断。
- **受控执行错误本地化与菜单栏警示恢复**：`mi-core` 与 `app/MicroInput` 将 `blocked:*` / `failed:*` 等受控无障碍错误码按中英语言本地化呈现，并在菜单栏图标、弹层警示卡与工作台页眉暴露非静默警示与一键「重试清理」恢复入口，同时补齐 `CleanupFailed` 与已退役六层清理护栏的恢复链路。
- **Antigravity 内置浏览器直达受控 AX 流程**：以受控无障碍流程替代 `Cmd+Shift+B` 快捷键，直接展开侧栏、按需新建标签、清理搜索框并确认地址栏或外置浏览器入口，同时剪除访客 `WebContentsView` 与设置页、Markdown 视图、聊天日志中的误匹配节点。
- **版本信息**：应用版本 `0.11.2`，build `14`。Bundle 标识、9 函数 C-ABI 边界、持久文档格式与 Sparkle 更新通道保持兼容。

全量离线门禁、静态检查与六个隔离 QA 场景（`host-execution`、`dsh-navigation`、`antigravity-status`、`config-write`、`lighting-control`、`diagnostic-export`）已通过自动回执校验；实机硬件交互与公证安装后状态按实机清单分别核验。
