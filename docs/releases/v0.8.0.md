# Micro Input v0.8.0

本版由 Micro Input 使用本机定义接管 Creator Micro 的全部控制位，修复原生 Codex 方案锁定时底部按键不执行的问题。现有键位和设备配置保留。

- Codex 前六个会话键支持状态筛选与原生导航，旋钮支持对话滚动和推理档位预设。
- 修复 Codex 多窗口聚焦和快捷键激活时切错窗口，沿用当前窗口执行。
- 控制接口保持独占，防止其他客户端同时连接；不改写外部应用插件。
- 应用图标改为 Creator Micro 硬件造型，并修复 Antigravity 侧栏导航。
- 删除未接入的导航与听写实现、旧单层编译器、无消费者的 Swift 展示状态和空构建参数，更新当前模块契约。
- 应用版本为 0.8.0，build 8。Bundle 标识与持久文档格式保持原值，内部 Rust crate 版本仍为 0.2.0。

工作台灯光编辑器的预览入口目前仅更新界面状态，尚未接入设备预览。

全量离线检查包含六个隔离应用场景。实体全部控件、语音音频、原插件重启重连及完整产品验收 #44 仍需分别验收，不以合成场景替代。
