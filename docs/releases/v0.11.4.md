# Micro Input v0.11.4

本版根除主窗与菜单栏弹层中全局「按键映射」开关承接默认键盘焦点导致空格误关整盘映射的隐患，并为菜单栏图标接入映射暂停三态提示与静态门禁 `R-C15`。

- **全局按键映射开关焦点隔离**：`NeutralSwitchToggleStyle` 新增 `allowsKeyboardFocus: Bool`，在 `false` 分支脱离 `Button` 并保留点击热区与无障碍按钮语义；主工作台顶栏与菜单栏弹层两处全局「按键映射」开关全部启用 `allowsKeyboardFocus: false`，同时主窗打开后清除默认 `firstResponder`，阻断窗口激活后按空格误关整盘映射的路径。
- **菜单栏三态视觉与悬浮提示**：`StatusItemIcon` 升级为 `Presentation` 三态模型（`.caution` > `.paused` > `.active`），在映射暂停时以半透明键体配右上角双竖线暂停徽标与中英双语悬浮提示即时反馈状态，并经 `observeStoreStatusItemState()` 与 `hostExecutionEnabled` 联动刷新。
- **结构化门禁与 AppKit 回归**：`scripts/check-boundaries.py` 新增 `R-C15` 静态门禁及正负 Python 单测；Swift 测试新增含对照组探针的真实 `NSWindow` 空格回归用例与 6 态模板图像渲染差异校验。
- **版本信息**：应用版本 `0.11.4`，build `16`。Bundle 标识、9 函数 C-ABI 边界、持久文档格式与 Sparkle 更新通道保持兼容。

默认并行度下的全量离线门禁、静态检查（`R-C01` 至 `R-C15`）与六个隔离 QA 场景（`host-execution`、`dsh-navigation`、`antigravity-status`、`config-write`、`lighting-control`、`diagnostic-export`）已通过自动回执校验；公证安装后的菜单栏实机观感与日常按键体验在安装版上同步确认。
