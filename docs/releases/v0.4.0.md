# Micro Input v0.4.0

本版合入 v0.3.0 之后的运行时收口与会话导航改进，交付六层 V2 逐键状态灯、Antigravity 侧栏无闪烁直达与单色中性界面设计系统。

- 下线 Cindy 集成与原生驻留权握手（#114），收紧输入生命周期、前台优先路由、焦点控件确认、HID 句柄宿主线程保活与原生无障碍会话确认管线（#116）。
- 六层方案升级至 V2，将第 2、3 层六个会话槽绑定为 `KV_OAI_AG06` 至 `KV_OAI_AG17`，支持从 V1 原位无损升级并完整保留第 0 层原始字节；`SharedVendorBridge` 统一承载 `v.oai.hid` 跨层去重输入、900 次请求前预轮换会话，并仅在 `v.oai.thstatus` 返回真实总线 ACK 后确认逐键状态灯同步。
- Antigravity 会话分类对齐 `Jetski Web` 对话列表口径，剔除子代理、分叉与侧问并持久化前台已选中对话的已读水位；会话跳转直接按精确 `/c/<conversationId>` 与 `projectId` 点击侧栏 `AXLink`，按需展开折叠侧栏、项目组与 `See all`，避免弹关搜索框闪烁。
- 原生工作台切换至单色中性表面设计系统（`UITheme`、`SurfaceButton`、无边框面板承载的 `SelectDropdown`、`NeutralSwitch`、`NeutralSlider`、`SettingsCard`），新增对齐 Creator Micro 2 物理 4x4 坐标的按键速查弹层，并由 `R-C09` 静态门禁与布局几何测试守卫。
- 日常应用版本为 `0.4.0`（build 4），内部 Rust crate 版本保持 `0.2.0` 不变。

发布验收覆盖静态边界门禁（`R-C01` 至 `R-C09`）、Rust 与 Swift 全量测试及隔离合成场景。实体按键、真实硬件灯效长时稳定性、真实语音、物理睡眠重连和长期运行仍需单独验收，见 #44；软件发布不将这些项目标为通过。

本版沿用现有 macOS 本机开发签名渠道，不声明公证或新的安装权限。
