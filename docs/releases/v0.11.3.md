# Micro Input v0.11.3

本版打通工作台双区 RGB 编辑弹窗到键盘原生的实时硬件预览链路，并稳定化 macOS 子进程超时测试的并发执行。

- **工作台原生灯光预览接线**：`mi-core` 引入四态状态机 `LightingPreviewState` 与 RAII 租约 `VendorBridgePreviewLease`，将 `LightingBeginPreview`、`LightingEndPreview` 与模态框实时编辑接入会话层 `Preview::begin_native`（支持 `0.6.3` / `0.7.0*`），异步启动零阻塞主线程，预览期间抑制后台 `v.oai.thstatus`、`kb.sa.rgb`、排队 v0.7.0 命令与 900 请求预轮转，同时保持物理按键事件畅通；关闭弹窗、切换上下文、断连、系统睡眠、六层挂起或 30 秒到期时自动排空停止。
- **会话层快停与整层替换**：`mi-session` 新增 `Preview::replace` 与 `Preview::begin_native_bounded`，修复空闲停止时的快速退出分支，原生结束不写 Flash 且不宣称自动恢复设备运行态。
- **单色 UI 硬件预览入口**：`LightingEditorSheet` 新增单色「在键盘上预览」/「停止预览」倒计时切换按钮，零扩充 Swift 投影桥接文件，同时补齐离线失败本地化回显与布局测试。
- **并发单测稳定化与文档对齐**：`mi-macos` 将 80ms 子进程超时测试中的 `/dev/null` stdin 校验隔离到独立 2 秒执行器并改用纯 POSIX 内建命令；同步更新 `docs/module-contracts.md`、`docs/status.md` 与 `docs/autonomous-delivery.md`（记录 `#37` 依 `R-C11` 退役）。
- **版本信息**：应用版本 `0.11.3`，build `15`。Bundle 标识、9 函数 C-ABI 边界、持久文档格式与 Sparkle 更新通道保持兼容。

默认并行度下的全量离线门禁、静态检查与六个隔离 QA 场景（`host-execution`、`dsh-navigation`、`antigravity-status`、`config-write`、`lighting-control`、`diagnostic-export`）已通过自动回执校验；Creator Micro 2 实体 LED 视觉效果与结束预览后运行态回读恢复仍按 `#24` / `#44` 实机清单核验。
