# Micro Input v0.9.0

本版升级无极旋钮交互契约与双覆层会话控制，为 Coding Agent（Antigravity、Codex、DSH Desktop）提供一致的模型选择与会话搜索体验。现有用户自定义按键与设备配置保持完整保留。

- 旋钮短按（Slot 15 / ENC_CLK）统一作为「弹出模型选择页」，进入模型选择覆层并启用硬件指针水平微滑与摇杆力度微调，再次短按确认生效。
- 旋钮长按（0.35s 保持）统一作为「搜索会话」（Cmd+K），进入会话搜索覆层并支持左右旋转上下挑选会话，再次短按确认；长按进入会话搜索时保持指针捕获关闭。
- 双覆层平滑切换：在模型选择打开状态长按触发搜索时，先清退指针捕获并发送 Esc 关闭宿主弹窗，再发送 Cmd+K 唤起搜索面板，杜绝快捷键被吞。
- 旋钮与摇杆防穿透防护：覆层处于激活状态时，按下旋钮转动不向背景穿透快速滚轮；前台应用切换、层级挂起、12 秒无操作或非覆层按键输入时自动关闭覆层并释放指针捕获。
- 迁移机制无损幂等：自动平滑迁移未修改的 pre-v0.8.0 与 v0.8.0 预设及六层持久化配置，用户个性化绑定不受任何影响。
- 按键速查与工作台文案完整双语对齐，应用版本为 0.9.0，build 9。
