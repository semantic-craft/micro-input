# Micro Input v0.9.0

本版调整旋钮（ENC_CLK）在桌面 Agent 方案下的默认控制契约，短按打开模型选择覆层，长按（350ms）触发会话搜索。现有用户自定义按键和设备配置保留。

- 旋钮短按（ENC_CLK）打开模型选择覆层，支持旋转切换候选项、水平指针微滑或摇杆调整推理力度，再次短按确认；前台应用切换、超时或非覆层按键输入时自动退出并释放指针捕获。
- 旋钮长按（350ms）触发会话搜索（Cmd+K），进入会话搜索覆层并支持旋转浏览，再次短按确认。
- 在模型选择覆层激活时长按触发会话搜索，先释放指针捕获并发送 Escape 关闭原弹层，再触发搜索，避免快捷键冲突。
- 覆层激活时按下并旋转旋钮不向背景窗口穿透滚轮事件。
- 自动迁移未修改的 pre-v0.8.0 与 v0.8.0 预设及六层持久化配置，保留已有自定义配置。
- 应用版本为 0.9.0，build 9。Bundle 标识与持久文档格式保持原值，内部 Rust crate 版本仍为 0.2.0。

全量离线检查包含六个隔离应用场景。实体全部控件、语音音频、原插件重启重连及完整产品验收 #44 仍需分别验收，不以合成场景替代。
