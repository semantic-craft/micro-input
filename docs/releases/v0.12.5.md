# Micro Input v0.12.5

本版修复 Karabiner-Elements 升级至 `17.0.0` 后全部按键失灵与无法自愈的根因，并新增 Antigravity 摇杆侧栏会话步进导航与一键归档后自动切入下一条会话工作流。

- **Karabiner-Elements 17.0.0 兼容与六层输入韧性自愈（PR #189）。** 动态解析 `karabiner_cli` 路径（优先匹配 Karabiner 17.0.0 的 `/Applications/Karabiner-Elements.app/Contents/Helpers/karabiner_cli`，兼容旧版路径）；按时间序贯通读取 `core_service.{3,2,1}.log` 与当前 `core_service.log`，避免日志轮转误判未抓取的同时仍严格拒绝 `stopped`/`terminated`/`(observed)`；`six_layer_runtime::resume()` 先完成 `wait_ready()` 再落盘 `six-layer-runtime.json`，失败时自动回滚 `karabiner.json` 避免残留死套接字；移除 3 次永久放弃上限，改为 `3s -> 5s -> 10s -> 20s -> 30s` 指数退避自愈，并将时钟偏移睡眠检测阈值放宽至 5 秒。
- **Antigravity 摇杆侧栏对话导航与一键归档自动续切（PR #189）。** 将 Antigravity 方案摇杆上/下（槽位 16/18）改为直接步进并滚动左侧会话导航栏（自动展开折叠侧栏、`AXScrollToVisible` + `AXPress` 与 500 毫秒 Hub URL 回读确认）；将槽位 7 由「聚焦当前输入框」替换为「归档当前会话」（`archive-conversation`），支持中英双语 AX 标签匹配、拦截运行中会话不误停，并在确认归档后自动切入下一条会话（末条回退至上一条）；启动时对存量 `workbench.json` 与 `six-layer-runtime.json` 自动原地迁移并保留全部自定义槽位。
- **仓库注释与历史文档清理（PR #188）。** 清理冗余文档注释与历史遗留文档，保持主干精简。
- **版本信息。** 应用版本 `0.12.5`，build `22`。Bundle 标识、9 函数 C-ABI 边界、持久文档格式与 Sparkle 更新通道保持兼容。

全量 `./scripts/check`（84 项 Python、全部 Rust 与 4 组 BFS 形式化模型、Swift 单测、`R-C01` 至 `R-C16`、注释棘轮与 Python AST 门禁）及 `MI_AUTO_HOST_READY=0 ./scripts/verify-offline` 六个隔离 QA 场景均已通过，并在实机 Karabiner 17.0.0 与 Antigravity 2.35.2 完成活套接字恢复、摇杆上下往返切换及连续归档实测。
