# Micro Input v0.10.1

本版合入 Antigravity Slot 8/Slot 9 预设加固、Side Question 侧栏提问支持，并完成 Rust 内核与 SwiftUI `@Observable` 薄壳的架构及性能优化，同时修复并行测试中的 AppKit 剪贴板竞态。

- 修复 Antigravity 默认第 9 键（`AG08`，`logical-8`）及第 10 键（`AG09`，`logical-9`）预设迁移的共享动作就地篡改隐患，统一通过 `rebind_starter_slot_action` 做隔离重绑与无引用清理，并对齐英文浏览器键帽文案。
- Antigravity 默认第 10 键（`AG09`）由「快速向右分栏」切换为「打开 Side Question」，支持原生辅助功能侧栏展开与聚焦输入框。
- Rust 内核落地 `RuntimeCommitStamp` 与 `AppBundleCache::generation` 空闲轮询短路门禁（保留 9 函数 C-ABI 与 `R-C14` `ffi_guard`），消除 `Cargo.toml` 未使用工作区字段警告，并为 `PasteboardRef` 增加 `PASTEBOARD_MUTEX` 跨线程保护。
- SwiftUI 薄壳解除 `WorkbenchRootView`、`ClassicWorkbenchView`、`CreatorMicroBoardView` 与 `CreatorMicroInlineInspectorView` 的域切片跨读与 `@State` 提前初始化，采用零拷贝 `Data(bytesNoCopy:)` 解码并新增有界 `HexColorCache` 与 `StatusItemIcon` 缓存。
- 应用版本为 0.10.1，build 11。Bundle 标识、9 函数 C-ABI 边界、持久文档格式与 Sparkle 更新通道保持兼容。

全量离线门禁与六个隔离场景（`host-execution`、`dsh-navigation`、`antigravity-status`、`config-write`、`lighting-control`、`diagnostic-export`）已通过自动回执校验；实机硬件与公证后宿主功能按实机清单分别核验。
