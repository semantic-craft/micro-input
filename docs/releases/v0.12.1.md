# Micro Input v0.12.1

本版为 Antigravity 通道新增只读后台日志存活感知、异常呼吸灯效与悬停原因提示，在保持正常执行默认熄灯的前提下，让模型自动重试、超时慢等、API 报错与后台断连在键帽和工作台上立即可见，无需干等。

- **只读增量日志解析与三类异常感知。** 有界尾读 `~/Library/Logs/Antigravity/language_server.log`（128 KiB 初始与轮转上限、`O_NOFOLLOW | O_NONBLOCK` 及 `(dev, ino, mtime, len)` 增量粘性缓存，夏令时安全 `libc::mktime` 跨年回卷，过滤监控噪音与用户主动取消），零 CDP 注入、零 `.patch` 且零对话正文读取。
- **按需亮灯与底部氛围灯联动。** 正常执行会话继续默认熄灯（`e = 0`，`sa: false`），已完成未读维持单键海蓝常亮（`#0088FF`，`e = 1`，`sa: false`）；当主会话或子代理等待审批、模型自动重试（`CallWithRetry` / `Run: attempt N failed`）、单会话超过 60 秒无进展慢等或后台 RPC 不可达 3–11 秒时点亮琥珀黄呼吸（`#FFAA00`，`e = 4`）并同步底光（`sa: true`）；当会话触发 `errorreport.go` API 报错（如 `429 RESOURCE_EXHAUSTED` 与重置倒计时）或后台断连满 12 秒时点亮珊瑚红呼吸（`#FF2200`，`e = 4`）并同步底光，支持 3 秒瞬时抖动保活、按次水印独立核销与点击槽位即灭。
- **工作台双语原因说明与无障碍对比度。** 会话列表、虚拟键帽与检查器统一接入中英双语悬停 `.help(...)`、`.accessibilityHint(...)` 及浅/深色 WCAG AA 自适应状态文字色；Codex 第 1 层（`AG00–AG05`）行为保持不变。
- **版本信息。** 应用版本 `0.12.1`，build `18`。Bundle 标识、9 函数 C-ABI 边界、持久文档格式与 Sparkle 更新通道保持兼容。

默认并行度下的全量离线门禁、静态检查（`R-C01` 至 `R-C15` 及零普通注释校验）与六个隔离 QA 场景（`host-execution`、`dsh-navigation`、`antigravity-status`、`config-write`、`lighting-control`、`diagnostic-export`）已通过自动回执校验；公证安装后的双源状态灯、存量 `workbench.json` 与 USB 连通已在实机同步确认。
