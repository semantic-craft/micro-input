# Micro Input v0.11.1

本版聚焦安全加固与 QA 隔离收口，强化本地私有文件/目录权限校验、应用包元数据解析、会话备份写入与 QA 运行器环境隔离，并完善发布公证与 TCC 清理流程。

- **本地私有存储与备份安全加固**：`mi-model`（`private_fs`）全面切换基于 `O_DIRECTORY | O_NOFOLLOW | O_CLOEXEC` 文件描述符的属主与 `0700`/`0600` 权限核验，防符号链接跟随与路径遍历；`mi-session`（`config_write`、`v070_hardware`）及 `mi-core`（`six_layer_runtime`、`v070_hardware_store`）的设备配置与恢复备份统一接入私有原子写入与恢复校验。
- **应用包发现与元数据解析加固**：`mi-macos`（`app_cache`）为 `Info.plist` 读取增加大小上限（1 MiB）、符号链接与路径规范化校验及安全子进程隔离，防止异常应用包或外部路径污染缓存。
- **QA 隔离与公证门禁修复**：加固 `qa_runner` 与 `scripts/run` 隔离运行边界，在注销 QA 临时包 LaunchServices 登记（`lsregister -u`）前先重置对应 QA TCC 授权，并将公证策略检查接入 `scripts/check`。
- **版本信息**：应用版本 `0.11.1`，build `13`。Bundle 标识、9 函数 C-ABI 边界、持久文档格式与 Sparkle 更新通道保持兼容。

全量离线门禁、静态检查与六个隔离 QA 场景（`host-execution`、`dsh-navigation`、`antigravity-status`、`config-write`、`lighting-control`、`diagnostic-export`）已通过自动回执校验；实机硬件与公证安装后功能按实机清单分别核验。
