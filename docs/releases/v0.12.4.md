# Micro Input v0.12.4

本版聚焦可靠性与结构化硬化，修复无序列号键盘写预算身份分裂、执行侧双语 AX 标签遗漏与自定义退役方案误删三项缺陷，新增 4 组零依赖 Rust BFS 形式化状态机模型检查器、自托管注释棘轮、Python AST 静态门禁与 GitHub Actions CI 工作流。

- **写预算统一身份、执行侧双语 AX 标签与安全方案迁移（PR #181）。** `discovery.c` 读取 `kIOHIDLocationIDKey` 填充 `HidCandidate.location_id`，统一 `device_sync`、`firmware_store` 与 `six_layer_runtime` 经 `DeviceBudgetRegistry::budget_for_candidate` 共享单设备写预算窗口；将 `NativeAxProvider::scroll`、`submit` 及 `grokbot_ax_labels::is_send_message` 全部收口至 `antigravity_ax_labels.rs` 并扩展 `R-C16` 静态门禁；`retired_unmodified_starter_profile_ids` 改为逐槽比对完整历史 starter 绑定与层设置，保留用户自定义 `Herdr` / `Qoder CN` / `千问办公` 方案；拆分 `ContainerIdentity` 与易变窗口标题。
- **约束注释类型化与自托管注释棘轮（PR #182）。** 清理 13 处复述文档注释与 3 处生产侧 `#[allow(dead_code)]` 测试构造器；以编译期有序常量断言、`#[serde(deny_unknown_fields)]`、`FreshDeviceBaseline` 与 `ConfirmedFlashAuthorization` 固化原本仅靠注释约定的安全边界；仓内自托管 `scripts/check_comments.py` 并由 `scripts/check` 无条件执行。
- **4 组零依赖 Rust BFS 形式化状态机模型（PR #183、#184）。** 新增听写租约与标题漂移（162 状态 / 1,782 转移）、`VendorBridge` 预览租约代次与外部改灯 CAS、`RadialMenuState` 确认所有权及 `DeviceSession` 单读响应路由与发送后取消守卫（2,362 状态 / 28,036 转移）形式化模型，全部在历史错误转移模式下稳定抓出最小反例轨迹，修复态零违例。
- **去除测试插桩与完善 CI 门禁（PR #185、#186）。** 移除 `commit_local_update_count` 与 SwiftUI 生产视图 `ViewRenderTelemetry` 插桩，改用 `projection_generation()` 与原生 `withObservationTracking` 验证切片隔离；保留全部安全、隐私、设备保护与端到端测试；新增 `scripts/check_python_scripts.py` AST 静态检查与 `.github/workflows/ci.yml`。
- **版本信息。** 应用版本 `0.12.4`，build `21`。Bundle 标识、9 函数 C-ABI 边界、持久文档格式与 Sparkle 更新通道保持兼容。

全量 `./scripts/check`（81 项 Python、全部 Rust 与 4 组 BFS 形式化模型、68 项 Swift、`R-C01` 至 `R-C16`、自托管零普通注释与 Python AST 校验）及 `./scripts/verify-offline --qa-only` 六个隔离 QA 场景均已通过。
