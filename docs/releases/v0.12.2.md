# Micro Input v0.12.2

本版落地 `worklouder/input-kit` v0.3.0 单设备滚动写入预算与零新依赖协议基础层，使实时切层、动态状态灯与设备写入统一受控于跨会话限流窗口，并为后续高频灯效、BLE 写入通道及可选本机 `19147` 插件兼容服务做好底座。

- **跨会话共享的单设备写入预算器（`mi-transport::budget`）。** 新增 `DeviceBudgetKey`、`DeviceWriteBudget` 与 `DeviceBudgetRegistry`，按物理设备身份维护 10 秒滚动写入预算（USB 60 次/10 秒，BLE 40 次/10 秒且间隔 ≥ 250 ms），并附带单连接 65 次/10 秒（160 ms 节流）的 `ConnectionRequestBudget`。`WorkbenchStore` 将注册表贯穿 `VendorBridge`，跨 900 次请求会话轮换与重连保持连续窗口计数。
- **非阻塞限流调度与流量分级（`mi-session`、`mi-core`）。** 新增单一枚举 `RpcTrafficClass`（只读查询、配置分片、控制写入）与 `SessionError::DeviceRateLimited`。预算获取与 BLE 间隔等待在锁定 `DeviceSession::queue` 之前执行，窗口耗尽时保持会话存活且不阻塞只读查询；多片 `fs.writebin` 按单次逻辑配置写入计费；`SaRgbRuntimeCoordinator` 按 `write_budget.next_ready_at` 自动退避，退出与紧急清灯通过 `WritePriority::UrgentClear` 跳过软间隔。
- **零新依赖 `InputKit` 协议契约（`mi-proto::input_kit`）。** 沉淀 `ws://127.0.0.1:19147/input` 7 个 JSON-RPC 2.0 方法、3 个服务端通知、`-32017` 限流错误响应、512 KiB 帧上限与 UTF-16 参数边界校验，直接复用 `SaRgbEffect` / `SaRgbUpdate` 并将 `SaRgbEffect::Off` 显式规范化为纯重置帧；本版不新增 Cargo 依赖、不监听本地网络端口，也不改动只读出口与界面布局。
- **版本信息。** 应用版本 `0.12.2`，build `19`。Bundle 标识、9 函数 C-ABI 边界、持久文档格式与 Sparkle 更新通道保持兼容。

默认并行度下的全量离线门禁、静态检查（`R-C01` 至 `R-C15` 及零普通注释校验）与六个隔离 QA 场景（`host-execution`、`dsh-navigation`、`antigravity-status`、`config-write`、`lighting-control`、`diagnostic-export`）均已通过自动回执校验。
