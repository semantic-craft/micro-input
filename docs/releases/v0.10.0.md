# Micro Input v0.10.0

本版升级桌面 Agent 方案下左上角旋钮的控制体验，左右旋转直接原位展开模型选择并首格推进，短按与长按旋钮统一触发会话搜索。现有用户自定义按键和设备配置保留。

- 旋钮左旋或右旋（ENC_CC / ENC_CW）无需先聚焦输入框或先按旋钮，直接通过辅助功能原位展开目标 Agent 模型选择并在首格同步移动候选项，随后支持水平指针微滑或摇杆调整推理力度，短按确认。
- 旋钮短按与长按（350ms，ENC_CLK）在无活跃弹层时统一触发会话搜索（Cmd+K），消除短按与长按阈值误触，进入会话搜索覆层后支持旋转浏览与短按确认。
- 通过辅助功能观测模型弹层展开状态（AXExpanded 与 Codex 弹层焦点守卫）；若用户已用鼠标点击或 Escape 外部关闭模型弹层，短按旋钮不再向宿主窗口误投递回车键，自动回落至会话搜索。
- 按住旋钮同时旋转保持快速滚动对话（FastScroll），在模型选择激活时长按旋钮仍先释放指针捕获并发送 Escape 关闭原弹层再打开会话搜索。
- 自动迁移未修改的 pre-v0.8.0、v0.8.0 与 v0.9.0 预设及六层持久化配置，保留已有自定义配置。
- 应用版本为 0.10.0，build 10。Bundle 标识与持久文档格式保持原值，内部 Rust crate 版本仍为 0.2.0。

全量离线检查包含六个隔离应用场景。实体全部控件、语音音频、原插件重启重连及完整产品验收 #44 仍需分别验收，不以合成场景替代。
