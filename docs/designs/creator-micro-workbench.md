# Creator Micro 原生工作台

工作台采用固定侧栏和内容页：Creator Micro、灯光、设备与连接、应用方案、动作库、径向菜单和通用。所有业务状态继续来自 Rust，经 CoreStore 的 Equatable 域切片投影；Swift 只维护页面选择和弹层显示。

## 浏览与控制

- 首页顶部显示实际宿主目标或按键控制暂停状态。六层的编辑选中与设备观察层分别显示。
- `BrowseProfile` 仅改变编辑方案与编辑层。`PreviewBoardLayer` 同时浏览该层分配的方案；空层清空编辑器，不沿用之前方案。
- 明确的“启用此方案”继续使用 `SelectProfile`；菜单栏原有切换行为保留。
- 应用方案负责六层分配、独立 USB 启动偏好、配置管理和导入导出。应用与恢复使用原有 Rust 流程。
- 设备比较、普通配置准备仍保留现有预览边界，不把合成快照称作新增实机能力。

## 排版

以用户确认的 Creator Micro E 稿为布局依据。只读核对本地 Codex 分发 CSS，采用其系统字体、28 px 应用标题、20 px 区段标题、14 px 正文与 4 px 间距基础，在 SwiftUI 中使用对应点数。辅助文字为 13 pt；字号与间距统一由 UITheme 定义。220 pt 侧栏与 880 pt 内容上限是本项目适配选择，不宣称是 Codex 的固定值。

侧栏暖灰、内容白色，单一紫灰强调色；采用分组、对齐和留白表达关系。窄窗口允许六层重排、文字换行及页面纵向滚动。主窗最低 820 × 640 pt。键盘布局沿用真实物理控件，详细编辑位于其下方；布局操作收进菜单。

参考资料是已安装应用的分发资源，不是公开桌面源码。不复制其实现或品牌资产。字体与间距原则另参考 GitHub Primer、Radix Themes 和 Carbon 的官方规范。
