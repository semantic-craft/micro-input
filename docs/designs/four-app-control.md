# 桌面应用控制

Micro Input 内置 Antigravity、Herdr、Codex、DeepSeek Harness 和 Cindy 五套应用适配。普通应用使用「其他软件」方案。选中画布上的键后可录制快捷键，默认的 Fn 语音键也可替换。需要固定某个应用时，可在动作中指定目标，或通过「应用关联」给它绑定方案。

| 方案 | 宿主入口 |
| --- | --- |
| Antigravity | 原生辅助功能动作与 Antigravity 状态桥。 |
| Herdr | 发往桌面版的快捷键，用于 Space、标签和分栏。 |
| Codex | 六层方案的第 1 层保留原生 OAI 映射，由 Codex 原生集成处理。出厂 `Mg1` 层继续保留编辑保护。 |
| DeepSeek Harness | 桌面版辅助功能与受限的同 Host 会话桥。 |
| Cindy | 原生快捷键、辅助功能动作与受限会话桥。原生所有权握手协调按键、听写与灯光。 |
| 其他软件 | 手动设置快捷键。可作用于前台应用，也可绑定具体应用。 |

工作台浏览和宿主激活是两种操作。切换宿主方案只更新本地路由。应用内入口缺失时报告不可用；按住听写只有在确认录音开始后才进入录音状态。会话、执行和请求分别绑定稳定身份；未确认的发送或审批不得自动重放。

启动时补齐缺少的 Cindy 内置方案。已有自定义方案和通用快捷键可继续使用。

## 六层并用

USB 六层方案使用以下固定位置。软件方案和蓝牙配对位置不等于物理层号。

| 物理层 | 三灯状态 | 默认用途 |
| --- | --- | --- |
| 1 | 亮、灭、灭 | Codex 原生集成 |
| 2 | 灭、亮、灭 | Antigravity，由 Micro Input 控制 |
| 3 | 灭、灭、亮 | DeepSeek Harness，由 Micro Input 控制 |
| 4 | 亮、亮、灭 | Cindy，由 Micro Input 控制 |
| 5 | 灭、亮、亮 | 空层 |
| 6 | 亮、亮、亮 | 空层 |

触控键短按依次切层；长按进入连接方式选择。三枚灯通过不同组合表示六层，并非只能切换三次。灯号与连接操作参见 [Creator Micro 2 官方设置说明](https://www.worklouder.cc/setup/creator-micro-2)。

Codex 原生集成没有独占某个编号。它监听 OAI 事件，所以只把这些事件留在第 1 层。第 2 至 4 层的按键、旋钮和摇杆改为独立普通键码，由已有 Karabiner 接管后传给 Micro Input。Cindy 的原生 Creator Micro 集成需要关闭，并通过当前连接的释放回执确认，避免两个原生消费者同时响应。

六层模式的听写键是“按一下开始，再按一下停止”。每次读取目标应用的实际录音状态，不靠本地布尔值交替猜测。合并宽键的两个微动只产生一次激活，两个微动都松开后才接受下一次。原来的按住说话方案独立保留，不能把它的松键停止说明用于六层模式。

六行配置首先保存为本地方案。点击“应用到键盘”才编译并写入设备；更改或预览某行不会提前改变运行中的按键归属。当前可应用的组合为表中的四应用加两空层，其他分配需要相应输入编码支持后才可应用。

应用前备份设备原文件和 Karabiner 原配置，先准备接收端和设备专属拦截规则，再写设备并完整读回。恢复时先恢复键盘并核验，再移除自有拦截规则。设备恢复未确认时保留拦截并停止派发。退出 Micro Input 也保留拦截，因此托管层不会因为 Micro Input 退出而向前台回放原键；Karabiner 自身必须保持运行。

设备配置读回、Karabiner 接管和收到首个实体按键分别显示状态。软件离线检查通过不表示实体按键、录音权限或蓝牙连接已经验收。

配置核验完成后关闭 Vendor RPC 会话，运行中的实体输入不再查询设备身份。每个受管按键的专用键码已包含层位，界面展示初次核验或最近输入层；未按受管键时，不声称实时知道用户切到了哪一层。USB 身份、Karabiner 规则与抓取、所有权和睡眠仍持续检查，失效后停止输入。外部工具在 USB 未断开时静默切换 Profile 或改写键图不属于持续核验范围，之后需要重新连接读回配置。

## USB 与蓝牙

Input 1.1.0 的静态研究显示，USB 和蓝牙连接按设备模型与序列号关联配置缓存，连接句柄分别管理。不要为同一把键盘创建两套互相覆盖的“USB Profile”和“蓝牙 Profile”。物理层分配、USB 启动偏好和蓝牙配对槽位分别保存。

本轮六层接管只开放已核对的 USB 设备。蓝牙端点的发现、重连和输入隔离仍需独立实测，不能把 USB 的设备位置过滤规则直接用于蓝牙。官方 Input 的 Profile 选择可能自动同步设备；只读调查不通过切换其 Profile 验证。

[接口索引](../four-app-interfaces.md)列出实现入口。[研究接入规则](../agents/research-context.md)说明设备证据边界。先用 `scripts/verify-offline` 核对软件；安装版目标应用、真实录音、实体按键和灯光效果另行核对。
